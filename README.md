# ⏰ Telegram Bot: Напоминалка

Мой первый Telegram-бот, написанный на Python с использованием библиотеки aiogram.

## 🎯 Что умеет бот
- Устанавливать напоминания на определённое время
- Показывать список активных напоминаний
- Очищать все напоминания

## 🛠 Технологии
- Python 3.11
- aiogram 3.x (асинхронный фреймворк)
- asyncio

## 📸 Пример использования
- /set 14:30 Позвонить маме
- /list
- /clear
